# Channel manager — demo call checklist

Ask every vendor the same questions and fill the same table. Verbal "yes, we
support that" is not enough for the items marked **[proof]** — ask them to show
it live on the screen during the demo.

Vendors to call: **AxisRooms**, **STAAH**, **eZee Centrix** (add Djubo if needed).

---

## A. Connectivity — the deal breakers

| # | Question | Why it matters |
|---|---|---|
| A1 | Is **Airbnb** a native two-way API connection, or iCal? **[proof]** | iCal syncs only availability, with a delay of hours — that is how double bookings happen. Only a native API is acceptable. |
| A2 | Are **MakeMyTrip** and **Goibibo** direct connections (not through a reseller)? **[proof]** | MMT + Goibibo is ~60% of Indian OTA volume. |
| A3 | Booking.com and Agoda — two-way, including **rate push and booking pull**? | One-way (availability only) means rates still have to be typed in each extranet. |
| A4 | What is the **sync delay** after a booking? Seconds or minutes? | Under 2 minutes is fine. Over 15 minutes is a double-booking risk on weekends. |
| A5 | Do you support **villa / unit-level inventory** (9 separate units, not room-type buckets)? **[proof]** | Our units are individually named villas, not "5x Deluxe". |
| A6 | Is there a **channel connection limit** in the quoted plan? | Some plans charge per extra channel. |

## B. Daily operation

| # | Question |
|---|---|
| B1 | Show the calendar view with 9 units for 30 days. **[proof]** |
| B2 | Can staff block a unit for maintenance/owner stay, and does it push to all OTAs? **[proof]** |
| B3 | Bulk rate update — change one date range across all channels in one action? **[proof]** |
| B4 | Seasonal / weekend pricing rules — supported? |
| B5 | Mobile app for booking notifications? iOS and Android? |
| B6 | How many staff logins are included, and are there role permissions? |

## C. Integration with our own systems

| # | Question |
|---|---|
| C1 | Is there an **API or webhook** we can use to receive bookings into the resort's own dashboard? |
| C2 | Can our existing website booking engine stay, with the website's inventory synced as a channel? |
| C3 | Do you provide a booking engine, and is it charged separately? |
| C4 | Do you support connecting an external WhatsApp provider (AiSensy / Interakt / Wati) via webhook? |
| C5 | Data export — can we export all bookings to Excel/CSV any time? |

## D. Content — confirm the honest answer

| # | Question | Expected answer |
|---|---|---|
| D1 | Do you sync **property photos** to the OTAs? | No — expect "content is managed in each extranet". If a vendor says yes, ask for a live demo, because this is not standard. |
| D2 | Do you sync descriptions and amenities? | Usually no, or partial. |

## E. Commercials

| # | Question |
|---|---|
| E1 | Exact monthly price for 9 units, all 5 channels — in writing. |
| E2 | One-time setup / onboarding fee? |
| E3 | Contract period and lock-in. Monthly or annual only? |
| E4 | What happens to our data if we cancel? |
| E5 | Any per-booking commission or transaction fee on top? |
| E6 | GST included or extra? |

## F. Support & onboarding

| # | Question |
|---|---|
| F1 | Who does the OTA mapping — your team or us? |
| F2 | Realistic go-live date after payment, including OTA approval time? |
| F3 | Support hours, and is there a dedicated onboarding person? |
| F4 | Support channel — phone / WhatsApp / email only? |
